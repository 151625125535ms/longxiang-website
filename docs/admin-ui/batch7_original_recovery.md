## 第一版设计的关键特征

### 全局外观

- 左侧深 navy 品牌侧栏，Logo 使用 Longxiang 黄色/蓝色组合。
- 侧栏不是简单文字列表，而是带图标、分组、展开箭头、当前项蓝色高亮、底部 Admin 用户区。
- 顶部 header 轻量，包含面包屑、语言、通知、快捷操作。
- 主内容区是浅灰页面背景 + 白色高质量面板，整体更像工业企业内部控制台，而不是普通后台表格。

### 内容管理

来源图：`admin-ui-batch7-concept.png`

关键结构：

- 左侧内容模块二级导航：
  - Hero 区域
  - 内容段落
  - 发展里程碑
  - SEO 设置
- 顶部有前台位置提示 banner：
  - 明确告诉用户内容显示在网站哪个页面和哪个区域。
  - 有“查看前台页面”按钮。
- 中间是结构化字段卡片，而不是裸 JSON。
- 右侧是上下文辅助栏：
  - 保存状态
  - 前台影响范围
  - 编辑提示
  - 快速操作
- 底部有关联证书表格，说明内容编辑不是孤立表单，而是和资源/证书关联。

这部分是第一版设计最重要的体验，不应退化成单栏字段表单。

### 产品管理

来源图：`admin-ui-batch7-products.png`

关键结构：

- 顶部操作区：新增产品、批量导入、刷新。
- 筛选区是独立面板，含搜索、状态筛选、分类、推荐筛选、清除筛选。
- 表格有真实缩略图、产品名、型号、分类彩色标签、状态、推荐 toggle、简介、更新时间、操作。
- 批量操作栏固定在底部，显示已选数量，并提供批量发布、批量下架、删除。

### 证书管理

来源图：`admin-ui-batch7-certifications.png`

关键结构：

- 顶部 tabs：资质证书、专利证书、软著、检测报告。
- 表格左侧，右侧固定证书预览面板。
- 证书表格展示真实证书缩略图、证书编号、颁发机构、颁发日期、状态。
- 右侧面板包含大图预览、元数据、文件路径、编辑、查看大图、复制路径。

这比后续简化版的 304px 小侧栏更完整，应按这张图恢复。

### 询盘管理

来源图：`admin-ui-batch7-inquiries.png`

关键结构：

- 左侧询盘表格 + 右侧详情面板。
- 顶部有搜索、状态 segmented filter、日期范围、更多筛选。
- 未读询盘用红点/红 badge，而不是只靠 row rail。
- 右侧详情面板包含客户头像、联系方式、询盘元数据、留言、跟进记录、底部主操作。
- 底部批量操作栏显示已选数量和批量动作。

### 控制台

来源图：`admin-ui-batch7-dashboard.png`

关键结构：

- 中间三列布局：
  - 待处理事项
  - 产品分类统计 donut chart
  - 最新询盘
- 底部：
  - 快捷操作
  - 系统状态

### 资源库

来源图：`admin-ui-batch7-assets.png`

关键结构：

- 顶部大面积拖放上传区。
- 搜索、类型筛选、排序、视图切换。

- 右侧选中文件详情：
  - 大图预览
  - 文件名、路径、大小、尺寸、格式

资源库的核心不是“卡片网格”，而是“资源使用位置可追踪”。
