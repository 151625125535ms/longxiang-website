# Project Documentation

This directory is the single home for project Markdown documents.

## Structure

- `admin-ui/` - Admin UI tasks, workflow, progress, and Batch 7 design specs.
- `cms/` - CMS optimization tasks, constraints, progress, and verified facts.
- `ops/` - API contract, workflow, optimization plan, and domain readiness notes.
- `import-logs/` - Product import logs.
- `assets/` - Asset source maps and usage notes.
- `protocol/` - Long-lived collaboration rules, code boundaries, handoff template, and review template.
- `tasks/` - Current or temporary task documents that can be deleted after completion.

## Root Exceptions

`AGENTS.md` and `CLAUDE.md` stay in the project root because agent tools expect those conventional filenames there.
